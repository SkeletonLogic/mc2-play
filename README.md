# MechCommander 2 - REBONED (browser)

MechCommander 2 playable in the browser. Play it from
<https://skeletonlogic.github.io/MacroslopBinbows/mc2/>, or directly at
<https://skeletonlogic.github.io/mc2-play/>.

* Needs a desktop browser with WebGPU (current Chrome or Edge).
* The first start downloads about 450 MB of game data into the browser's own
  storage; later visits reuse it.
* The GAME DATA panel can download or export a copy of the data packs. The
  downloadable zips are attached to this repository's latest release.

Microsoft published MechCommander 2 as shared source; see `EULA.md`, whose
terms govern this build. Original IP belongs to Microsoft/FASA. Free; no ads.
